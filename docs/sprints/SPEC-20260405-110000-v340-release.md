## Goal

Release v3.4.0 of the framework template, extracting four innovations from the derived project (journal/RepoCademy) into the canonical template. This release adds developer notifications, a solution-path knowledge system, a regression ledger extension, and reframes the educator agent for non-coding decision-makers.

## Context

The derived project has advanced beyond the template in several areas. The handoff document (2026-04-05) identifies reusable infrastructure that benefits all projects using the framework. The push notification system (ntfy.sh) is already implemented (`scripts/notify.py`, `.env.example`, `close_discussion.py` hook). The remaining work is documentation, the solution-path knowledge base, educator reframe, and open advisory resolution.

## Risk Assessment

- **Medium risk — educator reframe**: Changing the audience model is a significant philosophical shift. Risk of losing structural integration points or making the agent less useful for developer-audience projects. Mitigation: preserve all dispatch, capture, and persona safeguard sections; make the audience configurable in derived projects.
- **Low risk — solution-path KB**: Purely additive. Embeds into existing commands and rules. No new infrastructure.
- **Low risk — notifications**: Already implemented and tested. Only documentation remains.
