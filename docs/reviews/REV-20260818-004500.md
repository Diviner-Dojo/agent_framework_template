## BLOCKING findings — all three fixed in this change

### B1 — `/seed` mandated a principles block containing three pointers that dangle in a fresh seed
**Raised by**: independent-perspective. **Severity: BLOCKING.** **Status: FIXED.**

The block `/seed` required to be inlined verbatim cited `ADR-0031` (seeded `docs/adr/` is empty
by design), `PHILOSOPHY.md` § *Growth has a brake* (sourced from `~/.claude/shared-memory/`,
which on this machine **has no `PHILOSOPHY.md`**, with `|| true` swallowing the failure), and
`.claude/skills/selecting-review-gates/SKILL.md` (the scaffold created `agents/ commands/ hooks/
rules/` — **no `skills/`**). The verification step returned `7` and reported green regardless.

The same command's own prose forbids exactly this: *"a seeded project whose constitution is a
dangling pointer has no constitution at all."* The rule was applied to one pointer and not to
the three it introduced — the identical defect class ADR-0036 was written about, reproduced at
N× scale and verified green.

**Fix**: Step 1 now sources `PHILOSOPHY.md` from the template (shared-memory only as an override,
and only if current), **hard-fails** if the file or the cited section is absent, and hard-fails
if a `FRAMEWORK.md` ever lands in the target — mechanical enforcement, not prose (Principle #2).
Step 2 scaffolds `skills/` as required. Step 5 carries a re-pointing table so `ADR-0031` renders
as upstream provenance rather than a local document. Step 10 gained a pointer-resolution check
that would have caught this class.

### B2 — ADR-0036's central safety argument rested on a factually false claim
**Raised by**: independent-perspective. **Severity: BLOCKING.** **Status: FIXED.**

The ADR asserted *"`CLAUDE.md` is not in `FRAMEWORK_PATHS`, so it is never overwritten in a
derived project"* and rested the seeded-drift consequence on it. `scripts/lineage/manifest.py:24`
lists `"CLAUDE.md"` as item 3. Verified independently by the reviewer and re-verified by the
author against the same file the author had already read earlier in the session.

**This is the same error shape the ADR itself dissects** as the prior panel's "clean tell" — a
confident, unmeasured claim about a propagation channel. Same false premise, same file, inverted
subject.

**Fix**: the claim is corrected in place *and the correction is recorded rather than quietly
edited* — the ADR now states that `CLAUDE.md` **is** in `FRAMEWORK_PATHS`, that `/apply-framework`
offers it per-file for human acceptance, and that the property satisfying Prime Objective (c) is
*per-instance consent*, not untouchability. The decision is unchanged; the argument is repaired.

A second false claim in the same section — *"the public template stops publishing two mutually
contradictory principle lists"* — was found by the same reviewer and is also corrected. Measured
on `upstream/main`: public `CLAUDE.md` carries **nine** principles, public `PHILOSOPHY.md` says
*"Relationship to the eight principles"*, and **ADR-0031 was never promoted** (newest public ADR
is 0028). This converted a stated consequence into a **promotion requirement**: the promotion
carrying this deletion must also carry `CLAUDE.md`, `PHILOSOPHY.md` and ADRs 0029–0036, or the
public template ends up strictly worse.

### B3 — the ADR cited a review that predates the change and left B2 unresolved
**Raised by**: independent-perspective. **Severity: BLOCKING.** **Status: FIXED by this document.**

`ADR-0036` cited `REV-20260816-194513`, which pre-dates the deletion, the `/seed` rewire and the

the three highest-risk artifacts in the change.

**Fix**: this review. `ADR-0036`'s `review_id` now points here, and `discussion_id` is populated.

## HIGH — accepted, recorded, NOT closed by this change

  `all(isinstance(...))` over `{}` returns `True`, and `test_known_stale_counts_allowlist_does_not_rot`
  actively drives `KNOWN_STALE_COUNTS` toward empty (it is down to one entry). Both qa-specialist
  and independent-perspective landed on this test; qa-specialist demonstrated by execution that a
  keyset-**derived** register (`{k: "reason" for k in KNOWN_STALE_CITATIONS}`) is caught by the OLD

  reader**: that specific mutation is still caught, by a different test — 12 of the 13 derived

  the rewrite lost is its *locality*. Both reviewers judged the *deletion* of the old assertion

  it is a genuine push-blocker for the derived-project channel, distinct from the public channel.**

## Meta-finding

> **The author reproduced the exact defect class the author had just finished cataloguing —
> twice, in the artifacts written to fix it.**

A false `FRAMEWORK_PATHS` claim in ADR-0036, and three dangling pointers mandated by the same
`/seed` step that forbids dangling pointers. Both were written *after* the author had measured
the correct data (`FRAMEWORK_PATHS` was read earlier in the same session) and *after* teaching
the developer this precise pattern. Fluency with a failure mode is not immunity to it, and
self-review does not close the gap — the panel did. This is the strongest Principle #3 evidence
the effort has produced, stronger than the prior session's, because here the author was actively
looking for this class and still shipped two instances of it.
