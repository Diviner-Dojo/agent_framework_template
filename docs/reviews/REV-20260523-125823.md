## Blocking (must fix before commit)

1. **Escalate-only guarantee is prose, not mechanical (independent-perspective, Scenario A).**
   `reclassify_route` returns a route string and never mutates `ChangeItem.classification`, so an
   escalated `value-unverified` file is still in `package.stageable` — `stage()` would physically
   copy it. Only `distribute.md`'s "escalated non-empty → UNMEDIABLE → stage nothing" prose prevents
   the clobber. The floor was made mechanical; its escape hatch was left behavioral (B1-reborn if
   orchestration is ever ported to Python). **Fix:** make `stage()` escalation-aware
   (`exclude_paths`/`escalated_paths` that skips those files in the copy loop) + a regression test
   that an escalated file is never written even when present in `package.stageable`.
2. **No regression-ledger entry for B1 (qa-specialist F1).** The keystone test exists and is tagged
   `@pytest.mark.regression`, but `memory/bugs/regression-ledger.md` has no row linking it — the
   gate's regression guard can't anchor it. **Fix:** add the ledger row (B1, REV-20260523-065900,
   test function, fix date).
3. **`redact_secrets` fail-closed path untested (qa-specialist F2).** The `RuntimeError` raised when
   `_SECRET_PATTERNS_LOADED` is False is the last line of defence (staging uses `--no-verify`).
   **Fix:** monkeypatch the flag and assert it raises.
4. **`deleted`-drift `collision-diverged` branch untested (qa-specialist F3).** A target that deleted
   a file the hub re-adds must classify `collision-diverged`, not `inert`. **Fix:** add a test.
