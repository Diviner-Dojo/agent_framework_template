## Summary

Deep multi-agent review of the Phase 4 sourced-assertion memory substrate (assertion_store + mcp_server) immediately after end-to-end MCP-transport validation. Architecture is sound and code-level documentation is unusually strong, but ten unique blocking findings prevent commit-as-is — most importantly a **Critical** path-traversal vulnerability in `get_source` and a related URI-bypass in `_build_source_uri` that together would let any MCP caller read arbitrary files from the server's filesystem. Other blocking items: zero test coverage (including no regression test for the thread-local fix found this session), missing ADR-0014 for the largest architectural decision since ADR-0002, CLAUDE.md does not mention the substrate, module-import-time constants prevent derived-project reuse, and lazy model load creates a 1–3s first-call latency. Specialist convergence on the path-traversal finding (3 of 6 independent specialists named it) is the strongest signal.

### Architecture Consultant (confidence 0.88, model:opus)
- 9 findings: 4 blocking, 5 advisory
- The substrate/transport boundary is mostly clean (imports flow correctly, no reverse dependency) but the thread-local cache and the SQL bodies for `assert_fact`/`search_semantic` live in `mcp_server/server.py` instead of `assertion_store/`. ### Security Specialist (confidence 0.95, model:sonnet, --deep extended scan)
- 7 findings: 2 blocking (Critical + High), 5 advisory
- **CRITICAL — Path traversal in get_source**: A URI of the form `project://agentic-framework-template/../../etc/passwd` (or `../../.env`, `../../.ssh/id_rsa`) bypasses the project_id ownership check (which only verifies *who*, not *where*) and the existence check (which doesn't enforce containment). `relpath` extracted from the URI regex is used directly as `Path(relpath).read_text()`. **HIGH — `_build_source_uri` bypass**: the fast-path on line 71-72 returns any URI starting with `project://` unchanged, allowing callers to (a) write assertions tagged with a foreign project_id, corrupting boundary integrity, and (b) smuggle traversal sequences in bare path arguments via the construction branch. Also flagged: dependency pins (sqlite-vec is a C extension with full process privileges; the `>=` ranges are too permissive for a 0.x library); f-string DDL in substrate.py (not exploitable today because `EMBEDDING_DIM` is a literal int, but the pattern violates Rule 10); module-import path footgun; framing not validated; verbose error message echoes relpath. Explicit clean results on: vector embedding side channel, hardcoded secrets, MCP stdio authentication scope.

### Performance Analyst (confidence 0.87, model:sonnet)
- 5 findings: 1 blocking, 2 medium advisory, 2 low advisory

Fix: warm the model at server startup via `embed("")` after FastMCP construction so the cost moves to a context where the user expects it. Advisory: schema-init-per-thread costs are bounded by thread pool size (microseconds × ~5 statements × ~4–10 threads = noise); vector search post-filters by project_id after the ANN scan — fine at single-project scale but will silently under-deliver `k` in a mixed multi-project corpus (relevant for Phase 5 shared layer); `get_source` reads entire file into memory before slicing (fine for markdown, future concern at >1MB sources); `embed()` is single-call-per-text (future BAML pipeline will need a batch path).

## Required Changes Before Merge (10 blocking findings)

### Security (3) — must fix before any commit

1. **Path traversal in `get_source`** ([mcp_server/server.py:217, 231-235](mcp_server/server.py#L217-L235)).
   *Found by:* qa-specialist, architecture-consultant, security-specialist (3 independent specialists — strongest convergence signal in this review).
   *Fix:* After extracting `relpath` from the URI regex, resolve against the project root and enforce containment with `Path.is_relative_to()`:
   ```python
   PROJECT_ROOT = Path.cwd().resolve()  # module level
   # inside get_source, after extracting relpath:
   abs_path = (PROJECT_ROOT / relpath).resolve()
   if not abs_path.is_relative_to(PROJECT_ROOT):
       return {"error": "source_ref resolves outside project root", "source_ref": source_ref}
   ```
   Recommend further narrowing to `Path("sources").resolve()` since the tool's intent is source-document resurfacing. Add tests `test_get_source_path_traversal_rejected` and `test_get_source_valid_path_resolves`.

2. **`_build_source_uri` bypass** ([mcp_server/server.py:64-73](mcp_server/server.py#L64-L73)).
   *Found by:* security-specialist (unique).
   *Fix:* Remove the early-return fast-path. Always re-canonicalise: if the URI already has the `project://` prefix, parse it, extract the bare relpath, validate (no `..`), then reconstruct with the server's own `PROJECT_ID`. This ensures every stored assertion carries the current project's ID and that traversal patterns are rejected at write time, not only at read time.

3. **Module-import-time constants prevent derived-project reuse** ([mcp_server/server.py:38-39](mcp_server/server.py#L38-L39)).
   *Found by:* architecture-consultant (blocking), qa-specialist (advisory #7), security-specialist (advisory #5).
   *Fix:* Read both values with environment-variable overrides plus sensible defaults anchored to the script location:
   ```python
   _SERVER_DIR = Path(__file__).resolve().parent.parent
   DB_PATH = Path(os.environ.get("AGENT_MEMORY_DB", _SERVER_DIR / "data" / "memory.db"))
   PROJECT_ID = os.environ.get("AGENT_MEMORY_PROJECT_ID") or resolve_project_id(_SERVER_DIR)
   ```
   Required because Insight Journal needs `promotion_disabled: true` policy via separate DB; Howie needs its own project_id; tests need injectable values.

### Security & Robustness

### Architecture & Future-Proofing
- **Verify FastMCP type introspection works with `from __future__ import annotations`** ([mcp_server/server.py:26](mcp_server/server.py#L26)). - **Vector search post-JOIN project_id filter** ([mcp_server/server.py:158-181](mcp_server/server.py#L158-L181)): add `# TODO(phase5)` comment noting that `k` will under-deliver in mixed-project corpus until sqlite-vec metadata filtering or per-project partitioning lands.
