# Review: RepoCademy Education-Gate Plumbing

## Scope
New `scripts/education/` module (gate registry + untrusted-transcript ingest
chokepoint), `docs/education/{gates.yaml, CONTRACTS.md}`, ADR-0029,
SPEC-20260715-062207, and two test suites. Auto-scope: uncommitted changes on
`claude/voice-education-gate-walkthrough-7hlrnd`.

## Verdict
**APPROVE (post-fold).** Both reviewers returned approve-with-changes
(confidence 0.82 each); all 2 BLOCKING + 4 ADVISORY findings were folded
in-session. Final state: 68 tests, 93% coverage on the new module, ruff clean.

## Blocking findings (both folded)
1. **Terminal injection via unsanitized free text** (security-specialist).
   Transcript text/feedback/deferral-reason flowed unsanitized into
   `events.jsonl` and `gates.yaml`, later printed raw by `gate_registry list` —
   ANSI/control-character foothold for console spoofing.
   **Fold:** `_sanitize_text`/`sanitize_transcript` strip ANSI CSI/OSC
   sequences + control chars from every free-text field post-validation,
   pre-write; regression test feeds raw escape sequences and asserts both
   sinks are clean.
2. **Self-certification risk under-documented + client-nullable bar**
   (independent-perspective). Gate outcome is computed from client-asserted
   grades and a client-supplied threshold bounded only by (0,1]; no shipped
   file named the human evidence-PR merge as the load-bearing certification.
   **Fold:** trust-model paragraph in the module docstring, CONTRACTS.md §R5,
   and ADR-0029 Decision 4 (ingest = registration; human merge =
   certification); `MIN_PASS_THRESHOLD = 0.5` floor with test.

## Advisory findings (all folded)
- Total-payload DoS shape (2000×50k) → `MAX_TOTAL_TEXT = 2MB` cap + test.
- `chapter.number` `int()` coercion crash on crafted input → validated as a
  strict int with a type-confusion test.
- "All-or-nothing" overstated: per-row DB commits could strand rows behind the
  idempotency key with the gate un-flipped → all `education_results` rows now
  land in ONE SQLite transaction; docstring documents the crash-recovery path
  (`gate_registry.py clear`).
- `quiz_summary.average` was decorative → cross-checked against recomputed
  grade average (±0.01) with test.
