## The veto fired, and was cleared by the same discipline that raised it

**S7 round 1 (VETO).** The slice deleted the only test that drove `--rebaseline` end-to-end
through `main()` and replaced it with unit tests on a pure helper. Its own headline guarantee —
*"no invocation of this script can add a fingerprint to `config/gate_baseline.json`"* — became
unfalsifiable. The critic **proved** it: restored the literal pre-fix defect
(`_write_baseline(current_fps)` after `_print_baseline_proposal`) and the suite stayed
**163/163 green**. The guard had been moved out of a test and into a docstring — breaking, in
the same change, the rule stated one row above it: *a test that stays green when you break the
thing it guards is not evidence*.

**S7 round 2 (PASS).** The CLI test is restored and mutation-proven: the same defect now yields
**7 failed / 166 passed**, and **1 failed / 166 passed** even with the new class deselected, so
the guarantee is doubly held. Four independent mutations each red a different, predicted set.
