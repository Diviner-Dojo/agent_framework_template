## Blocking findings — all fixed in the revision pass

**B1 (HIGH, independent-perspective) — the safety fix shipped a safety gap.**
`git add --intent-to-add --all` promotes a worktree DELETION of a tracked file to a **staged
deletion**, which a `??`-scoped reset cannot reach. Reproduced independently by the facilitator
on a throwaway repo: after `-N` the index held `0	1	sibling.txt`; the shipped `??`-scoped
reversal left it; `git commit -m` (no `-a`) then committed the unrelated deletion
("1 file changed, 1 deletion(-)"). The retained measured sentence *"after it,
`git diff --cached --numstat` is EMPTY and `git commit -m` refuses"* is FALSE in that state —
and the slice had just re-scoped it to its only surviving copy.
**Fixed**: both fences capture ` D` paths as well as `??`, reverse both, and end with a
`git diff --cached --numstat` verify step; the EMPTY claim is qualified to the tree it was
measured in.

**B2 (HIGH, independent-perspective) — R4 was self-refuting.** The pointer restated
`MECHANICALLY-CLEAR may never be promoted to VERIFIED` verbatim *and* claimed it was "stated
once", taking the count in `review.md` from 1 to 2. **Fixed**: restatement removed (count back
to 1), and guarded by `test_the_stable_phrase_is_stated_once_not_restated_beside_its_pointer`.

**B3 (HIGH, architecture-consultant) — `subsection()` was fence-blind.** A `#` bash comment at
column 0 read as a markdown heading, so the helper returned **194 characters** of a
multi-hundred-line section — truncating at a comment this diff added. **Fixed**: fence-aware
masking; the same call now returns 7,541 chars and contains both the reversal and `named 14`.

**B4 (MEDIUM→blocking by convergence, all three) — the shipped safety mandate was unpinned.**
`git grep "git reset" -- tests/` returned nothing: the entire Advisory-3 closure had zero
regression protection while the pointer prose around it was pinned. **Fixed**: additive class
`TestTheIntentToAddIsReversed` in `tests/test_paths_not_taken.py` — 3 regression tests × 2 files
(reversal present; never the unscoped form; deletion hazard named).

**B5 (MEDIUM, all three) — `POINTER_FLOOR` was 3 against an actual 4.** qa demonstrated the
consequence live: deleting R3's entire cross-file pointer left all 316 tests green. **Fixed**:
floor raised to 4, docstring arithmetic corrected, plus a named per-requirement pin
(`test_the_cross_file_pointer_r3_added_is_specifically_present`).
