## Recommended Improvements (Non-Blocking)

### New low advisories from this re-review

1. **Reversed line-range silent empty string** ([assertion_store/substrate.py:484-488](assertion_store/substrate.py#L484-L488)). `get_source(#L10-L3)` silently returns `{"passage": "", ...}` via Python's slice behaviour for `lines[9:3]`. *Fix:* add `if start_i <= 0 or end_i < start_i: return {"error": ...}` guard + test.

2. **Missing TODO comment in code** ([assertion_store/substrate.py:379](assertion_store/substrate.py#L379)). ADR-0014 claims a `TODO(phase5)` is in place noting the vector search post-filter limitation in mixed-corpus queries. The code lacks the comment. *Fix:* add the TODO at the WHERE clause so a Phase 5 implementer reading source finds the constraint.

3. **`mcp_server/__init__.py` docstring is minimal** ([mcp_server/__init__.py:1](mcp_server/__init__.py#L1)). Single line vs `assertion_store/__init__.py`'s 10-line docstring. *Fix:* expand to name the three tools, identify this as a thin FastMCP transport over `Substrate`, note the env vars, point to ADR-0014.

4. **Semantic-distance calibration not durably captured** (currently in `docs/dispatches/phase4-canonical-test-handoff.md` only). Observed distance ranges from the canonical test and the "ordering matters more than absolute distance" insight should land in ADR-0014 Neutral Consequences or `memory/projects/_self.md` Solution Paths. *Fix:* one bullet in either location.

5. **Warm-up edge case** (advisory micro). `embed("")` at server startup — if `all-MiniLM-L6-v2` has degenerate behaviour on empty input, `embed("warmup")` would be marginally safer. *Fix:* one-character change.

### Carry-forward advisories from REV-20260512-132622 (still open)

6. **F-string DDL pattern in `substrate.py:115-163`** — not exploitable today (`EMBEDDING_DIM` is a literal int), but pattern violates REVIEW.md Rule 10. *Fix:* add `assert isinstance(EMBEDDING_DIM, int) and EMBEDDING_DIM > 0` or document the deliberate use of f-string for a hardcoded constant.

7. **Three new deps not pinned to `==`** (`sqlite-vec`, `sentence-transformers`, `fastmcp` in [requirements.txt:12-14](requirements.txt#L12-L14)). Supply-chain hygiene. *Fix:* pin to the tested versions. Deferred to ship per prior review.

8. **`from __future__ import annotations` × FastMCP introspection** ([mcp_server/server.py:19](mcp_server/server.py#L19)) — still unverified post-refactor. *Fix:* inspect FastMCP-registered tool JSON schemas; if types degrade to "string"/"any", remove the future-import from server.py only.
